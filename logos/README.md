# Mechanical Temp Logos

## Structure
Organized by BACKGROUND color of the file:

- `black/` — files with black backgrounds (logo is white/light)
- `white/` — files with white backgrounds (logo is black/dark)

Within each color folder:
- `full/` — Complete logo (icon + wordmark together)
- `icon/` — Just the symbol/icon
- `text/` — Just the wordmark only
